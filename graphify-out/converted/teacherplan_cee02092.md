| 晨间活动： | 重点指导：自主游戏《给小动物喂食》
活动目标：
学习将沙包等轻物向前上方投掷，尝试投入一定距离的容器中。
发展手眼协调能力和手臂力量。
激发关爱小动物的情感。
指导要点：
设置多个不同高度、大小（开口由大到小）的“动物嘴巴”（篮子、纸箱），并贴上动物头像，拉开不同投掷距离。
示范肩上投掷动作：小手举过肩，用力向前投。允许幼儿用自己习惯的方式（如胸前抛）尝试。
鼓励幼儿为不同“动物”喂食。不强调投中率，重点鼓励大胆尝试和积极参与。 |

| 集体活动： | 活动过程：
一、暖场：欢迎回家
师：宝贝们，新年好！欢迎回到幼儿园，回到我们最温暖的小四班！
师：一个寒假没见，老师真想你们呀！来，让我们先给旁边的好朋友一个大大的微笑！
二、红色分享篇：我的寒假小故事
师：瞧，这是什么颜色？（红色）
师：红色代表热闹和开心，就像我们刚刚过完的新年一样！
师：（打开PPT寒假时钟）老师这里有个神奇的寒假时钟，指针转啊转，会停在哪里呢？
师：（邀请幼儿点击或教师随机停在一个图标上）哇，停在了这个图案上！这是“年夜饭”的意思。
师：谁愿意来告诉大家，过年的时候你吃了什么好吃的？和谁一起吃的呀？
（请2-3名幼儿分享，教师给予积极回应）
师：原来大家的寒假都过得这么精彩！有人吃了好吃的，有人收了红包，还有人去旅游了！
师：我们把这份快乐带回幼儿园，一起开开心心开始新学期！
三、橙色游戏篇：好朋友，抱一抱
师：一个寒假没见，你想不想你的好朋友呀？
师：让我们一起玩个游戏，庆祝我们的重逢吧！
师：（出示“好朋友庆祝小路”地贴）看，这是我们的“好朋友庆祝小路”。
师：两个好朋友手拉手一起走，走到每个图片前面，就一起做图片上的动作。拉拉手、击个掌、抱一抱……
师：做完一个动作，要大声说“橙了”！然后继续往前走。谁想先来试试？
（请一对幼儿示范，然后鼓励幼儿自由组队游戏，教师为完成游戏的幼儿贴上好朋友贴纸）
师：和好朋友抱一抱、转个圈，你心里感觉怎么样？
师：是呀，回到幼儿园，有这么多好朋友，真是太开心啦！
四、黄色发现篇：教室里的新变化
师：你们发现了吗？我们的教室也悄悄变了样！
师：老师这里有一些“金闪闪线索卡”，上面画的地方，藏着新变化。
师：（展示线索卡）这张卡片上画的是哪里？（图书角）
师：好，请第一组的小朋友拿着线索卡，去图书角找一找，那里有什么新东西？
（分组寻找，找到后回到座位分享）
师：你们找到了什么？（一本新书）哇，这是我们班的新朋友！
师：（对其他组）你们找到了什么？（植物角开了一朵小花）真漂亮！
师：原来我们的教室里多了这么多新朋友！有新的书、新的玩具、新的小花……
师：因为有了这些，我们的教室变得更漂亮、更温暖啦！
五、青蓝巩固篇：我们的约定，安全最重要
师：长大一岁了，我们要做更棒的自己。让我们一起来回忆一下我们的小约定！
师：（出示图片）玩完玩具，小手脏脏的，这时候应该……？
幼：洗手！
师：对了！洗手要用什么方法？
（带领幼儿简单回顾洗手步骤）
师：（出示图片）老师在讲故事的时候，我们要……？
幼：安静听！
师：真棒！还有，玩完玩具，音乐响了，我们要……？
幼：送玩具回家！
师：太棒了！你们把这些约定都记得牢牢的！
师：接下来要考考大家是不是安全小卫士！
师：老师说出一种行为，如果你觉得是安全的，就举起蓝色牌；如果是危险的，就举起红色牌，或者比个叉。
师：过马路牵着妈妈的手  师：安全吗？
幼：安全！（举蓝牌）
师：排队洗手时推来推去  师：可以吗？
幼：不可以！（举红牌）
师：陌生人给你糖果，说要带你去玩  师：能去吗？
幼：不能！（举红牌）
师：哇！你们都是合格的安全小卫士！把这些安全知识记得这么清楚！
六、紫色收尾篇：跳起来，新学期快乐！
师：今天我们一起分享了寒假的故事，和好朋友玩了游戏，还找到了教室里的新变化。
师：最后，让我们一起跟着《开学歌》跳起来，庆祝我们的新学期吧！
（播放音乐，教师带领幼儿简单律动）
师：新学期开始啦！祝每个小朋友在幼儿园都开开心心，每天都有一点小进步！ |
| 室内区域游戏： | 游戏区域：生日坊、娃娃家等 |
| 室内区域游戏： | 重点指导：生日坊
活动目标：
通过扮演“糕点师”，模仿和面、揉搓、装饰等制作过程，获得角色扮演的快乐。
在操作“面团”（彩泥或真实面团）的过程中，进一步锻炼手部揉、捏、按、搓等精细动作。
学习简单的游戏交往规则，如轮流使用工具、协商角色。
指导要点：
创设真实有趣的“厨房”环境，提供围裙、厨师帽、塑料刀具、模具、压面机等安全仿真实物。
以“新年做糕点”为主题，引导幼儿制作“汤圆”、“饺子”、“饼干”，将美工与角色游戏结合。
引导幼儿将“作品”进行“售卖”或与“娃娃家”联动，拓展游戏情节。 |
| 室内区域游戏： | 支持策略：
定期提供安全无毒的彩泥或真实的面团（仅限揉捏玩耍，不食用），保持材料的新鲜感。
展示真实糕点的图片或简单食谱卡片，激发幼儿模仿创作的兴趣。
将幼儿的“烘焙作品”陈列在橱窗，增强其游戏成就感。 |

| 下午：
户外游戏 | 重点指导：球类区
活动目标：
通过滚、抛、踢、拍（手眼协调拍）等动作玩球，发展手眼、脚眼协调能力及对物体运动轨迹的判断。
体验与同伴互动玩球的乐趣，如互相滚球、合作传球。
建立基本的器械收纳意识，玩完后能将球放回球筐。
指导要点：
提供尺寸、重量、弹性适合小班幼儿的大号软质球。活动场地需有围栏或明确边界。
从最简单的动作开始指导，如双手抱球、蹲下滚球给老师。逐步增加抛接、踢球等难度。
设计情境化游戏，如“给小熊送西瓜（滚球）”、“赶小猪（用脚推球）”，让技能练习更有趣。 |
| 下午：
户外游戏 | 支持策略：
设置不同难度的目标，如宽口球门、低矮的篮球架、地面上的目标圈，让每个幼儿都能体验成功。
利用墙面或地面画线，玩“球碰墙”、“球沿线走”等游戏，降低对动作精准度的要求。
播放节奏明快的音乐，组织集体“球操”或“滚球大赛”，提升活动气氛。 |
| 一日活动反思： | 本次活动以“开学了”为主题，通过红、橙、黄、青、紫五种颜色贯穿始终，形式新颖，环节清晰，孩子们在丰富的游戏中自然过渡到新学期。活动中，孩子们不仅积极分享寒假趣事，还在寻找教室新变化的过程中增强了归属感。通过“安全小卫士”的互动问答，孩子们进一步巩固了常规与安全知识，目标达成度高。整个活动氛围温馨活跃，有效缓解了幼儿的返园焦虑。今后可适当增加幼儿自主表达的时间，让分享更充分。 |
