# 桌面数据、凭据与备份设计

## 1. 本地数据权威

应用管理一个 SQLite 数据库。用户不在每次启动时选择数据库文件，避免误开副本、在网盘
目录中直接运行或同时编辑多个数据库。数据库启用外键约束并使用适合桌面单进程的事务；
不得把 SQLite 文件放入 WebDAV、S3 或自动同步文件夹直接打开。

首期最小实体为应用资料、幼儿园设置、班级、班级区域、学期、教案、教案版本、日历人工
覆盖、AI 非敏感配置、AI 预览和备份清单。首期不得出现幼儿、照片、观察记录或倾听记录表。

## 2. Schema 迁移

每个发布版本声明可识别的 Schema 版本。升级流程固定为：

1. 检查数据库完整性和可写空间。
2. 创建升级前完整备份并校验。
3. 在事务允许的范围内执行顺序迁移。
4. 验证目标 Schema 与关键计数。
5. 成功后启动应用；失败时保留原数据库和升级前备份并停止写入。

不得在应用启动时使用 `create_all()` 隐式修改已有正式数据库。

## 3. 保存、版本与归档

- 同一 `(class_id, plan_date)` 只有一份当前教案。
- 停止输入约 3 秒后自动保存当前正文，不创建版本。
- 显式保存版本可以包含用户说明。
- 采用 AI 预览先保存采用前版本，再更新正文。
- 恢复历史、归档和恢复归档记录操作前状态，历史版本不可变。
- 归档教案默认只读。
- 单教师单进程首期不实现多人乐观锁；仍须防止同一窗口异步结果覆盖已变化正文。

## 4. 凭据存储

以下秘密不得进入 SQLite、备份、日志、异常或测试快照：

- AI API Key
- WebDAV 用户名关联的密码或令牌
- S3 Secret Key 与会话令牌
- 为自动备份暂存的备份恢复口令

应用通过稳定服务名和账号键访问操作系统凭据存储。SQLite 只保存非敏感 Endpoint、模型名、
Region、Bucket、路径前缀和“凭据是否已配置”状态。删除配置时必须同时删除对应凭据项。

Windows 只接受 Credential Locker 的 Windows backend，并固定 `local-machine` persistence；
Linux 只接受 `keyring.backends.SecretService.Keyring`，使用当前用户的 Secret Service 登录
keyring，记录为 `local-user` persistence。Null、明文文件、未知或只伪造显示名的 backend 均
fail closed，且不得回退到环境变量、普通文件或 SQLite。Linux Secret Service 不可用或锁定时，
只关闭依赖凭据的外部能力，不阻断手工教案流程。详见
[ADR-0014](../ADR/ADR-0014-cross-platform-desktop-credential-storage.md)。

## 5. 备份包

本地备份包至少包含：

- 备份格式版本与应用标识
- 创建时间、应用版本和 Schema 版本
- SQLite 一致性快照
- 必需的非敏感资源清单
- 每个载荷的长度和 SHA-256

本地手动备份可以作为完整备份包保存。上传 WebDAV/S3 前，整个载荷必须使用独立恢复口令
派生的密钥在本机认证加密。加密格式必须具备随机盐、随机 nonce、明确的 KDF 参数、版本和
AAD；具体算法在实施计划中通过标准库/维护良好依赖和兼容性验证确定，不自创密码协议。

远端对象名不得包含教师姓名、幼儿园名称、班级名称或教案正文。建议只包含应用标识短名、
UTC 时间、随机备份 ID 和格式版本。

## 6. 备份与恢复流程

### 自动本地备份

- 每日首次成功打开数据库后创建一次。
- 默认保留最近 30 份每日备份。
- 数据库迁移和恢复前备份不受每日轮换立即删除。

### 远程备份

- WebDAV/S3 只是单向对象存储目标。
- 上传前完成本地快照、校验和加密。
- 上传成功后再次读取可用元数据或对象长度进行确认。
- 远程失败只更新备份状态，不影响本地数据库事务。

### 恢复

1. 用户明确选择本地或远程备份版本。
2. 远程备份先下载到专用临时目录。
3. 输入恢复口令并完成认证解密和完整性校验。
4. 检查应用标识、格式和 Schema 可迁移性。
5. 自动备份当前数据库。
6. 原子替换数据库并重新验证；失败时恢复原状态。

没有正确恢复口令时不得尝试弱化验证或提供万能恢复。

## 7. 非同步保证

产品文案和 UI 不使用“同步”“云端实时”“跨设备一致”等表达。两个设备分别恢复同一个备份
后形成独立副本；应用不上传增量、不比较教案版本、不自动选择最新备份，也不合并修改。

## 8. 威胁与验证

- 错误口令、密文篡改、截断、错误应用标识和未知格式必须拒绝恢复。
- 日志脱敏测试必须覆盖 URL 用户信息、Authorization、API Key、Secret 和恢复口令。
- 远程适配器测试使用本地替身，不访问真实用户服务。
- 断电/强制退出测试覆盖自动保存、迁移、备份生成、下载和替换窗口。
- 备份示例和截图只使用虚构教师、班级与教案。
