# 桌面界面设计系统

## 1. 体验目标

界面是现代、克制的 Windows 桌面办公工具，而不是网页仪表盘。长文本编辑空间、清晰上下文、
稳定状态反馈和键盘可用性优先于装饰、动画和卡片数量。

首期提供浅色、深色和跟随 Windows 系统三种主题选择，参考 Windows 11 Fluent 的层级与
间距，但不依赖第三方 Fluent 控件库。主题必须由同一组语义令牌派生，不允许页面分别维护
两份样式。

## 2. 信息架构

首期主导航只显示：

1. 一日活动计划
2. 数据与备份
3. 设置

历史版本属于当前教案上下文，可从教案页进入，不作为全局业务模块。观察记录、一对一倾听、
幼儿档案和同步不显示空入口。

## 3. 视觉令牌

原型阶段使用以下初始令牌，最终值由 Windows 实机评审调整：

- 字体：`Microsoft YaHei UI`，回退 `Segoe UI` 与系统 sans-serif
- 正文：14 px 等效尺寸；辅助信息 12 px；页面标题 22 px
- 间距：4、8、12、16、24、32
- 圆角：输入与按钮 6，面板 10
- 主色：克制蓝绿色；危险与错误使用红色；警告使用琥珀色
- 背景：浅灰应用底色、白色编辑表面、清晰但低对比边界
- 图标：单一 SVG 线性图标集，禁止 emoji 充当正式图标

颜色和尺寸必须集中定义；页面不得散落独立 StyleSheet 字符串。

## 4. 已确认教案编辑布局

原型曾提供三个结构不同的方案，而非只换颜色：

- A：经典三栏。左侧导航与日期，中间长文编辑，右侧可折叠 AI 助手。
- B：聚焦编辑。左侧紧凑日期轨道，中间单栏目沉浸编辑，AI 以底部工作台呈现。
- C：周计划工作台。顶部周日期带，左侧栏目目录，右侧编辑与预览分区。

三个方案共享相同虚构数据和操作状态，并使用底部原型切换器。原型只回答布局、密度、层级
和状态可见性，不连接数据库或真实 AI。

2026-08-08 最终确认以 **C — 周计划工作台** 为正式设计方向。顶部周日期带每一天必须同时
显示日期、星期和当天集体活动主题。日期带上方提供明确的“上一周”“下一周”和“回到本周”
按钮，并显示教学周次与日期范围。右侧保留 AI 建议对照，使教师在采用前能同时看到正文和
生成结果。B 保留为比较过程，不再是正式设计方向。

C 的 01–05 编辑区必须与固定 Word 模板保持语义同构：

- 01 晨间活动：固定项目、集体游戏、自主游戏、重点指导、活动目标、指导要点。
- 02 晨间谈话：话题、问题设计。
- 03 室内区域游戏：游戏区域、重点指导、活动目标、指导要点、支持策略。
- 04 下午户外游戏：与室内区域游戏相同的五组字段。
- 05 集体活动：活动主题、活动目标、活动准备、活动重点、活动难点、活动过程。
- 06 一日活动反思：活动亮点、存在问题、调整策略。

左侧栏目按钮切换结构化编辑面板；字段可以为适应屏幕重新排列成两列，但字段边界、名称和
导出映射不得丢失。长字段使用面板内编辑区或垂直滚动，不把 Word 视觉表格逐像素复制到桌面。
双栏中同一行的两个字段卡片必须等宽、等高，编辑区高度取该行内容需求的较大值；无法自然
配对的单个字段占满整行，避免出现底边错位或仅悬挂在左列的卡片。
集体活动面板固定采用“主题与准备双栏、目标整行、重点与难点双栏、过程整行”的屏幕排列。

### Word 导出入口

右上角使用拆分按钮：主按钮直接导出当前选中日期，箭头菜单提供“批量导出日期范围…”。
批量弹窗选择同一学期内的开始和结束日期，先展示导出数量及跳过日期原因，再确认合并导出。
生成中的进度、取消入口与最终保存位置属于同一导出流程，不用多个连续确认框打断教师。

原型入口：`apps/desktop/prototype_daily_plan.py`。一次性运行命令：

```bash
uv run --with PySide6==6.11.1 python apps/desktop/prototype_daily_plan.py
```

## 5. 固定状态位置

- 当前班级、日期和教学周始终可见。
- 自动保存状态显示在标题或底部状态区，不用成功弹窗。
- AI 状态显示任务类型、进度和取消入口，不覆盖正文。
- 备份状态显示上次成功时间和失败重试，不把远程失败渲染成数据丢失。
- 阻断式对话框只用于恢复备份、放弃未保存内容等不可逆或高风险确认。

## 6. 可用性与无障碍

- 1366x768 是最低可用窗口，辅助区域可折叠，主要操作不水平滚动。
- Windows 125% 和 150% DPI 下不得裁切文字或固定像素挤压按钮。
- 所有输入有可见标签；颜色不是错误和状态的唯一表达。
- Tab 顺序、快捷键和焦点轮廓可见；长文本编辑保留系统复制、粘贴、撤销和选择行为。
- 后台工作不冻结主窗口；关闭窗口时对仍运行任务给出明确处理结果。

## 7. 主题行为

- 设置提供“跟随系统、浅色、深色”，默认跟随 Windows 系统。
- 原型可以用窗口内按钮快速切换浅/深；正式实现必须监听系统主题变化并持久化显式选择。
- 主题切换只改变语义颜色令牌，不重建页面、不清空焦点和未保存内容。
- 深色表面采用分层深灰绿色，不使用纯黑大面积背景；编辑区、输入、选中、禁用、成功、警告
  和错误均有独立令牌。
- 所有文本和交互状态必须在 Windows 实机上检查对比度；颜色不能作为状态的唯一提示。
