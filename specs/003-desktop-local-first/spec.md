# Feature Specification: 幼儿园管理助手桌面首期

**Specification Branch**: `design/desktop-local-first`

**Implementation Target**: `dev`（仅在本规格确认、收敛到 docs 且 Issue 固定完整 docs SHA 后）

**Created**: 2026-08-08

**Status**: 已确认

**Design Review**: 2026-08-08 通过；受控 Agent Design Amendment 同日冻结单 Agent、
Application Layer、Tool-only、确认写入、无长期业务记忆及分阶段解锁；已核对首期/下一期边界、
固定 Word 模板字段、幼儿信息禁入、单机无登录、备份非同步、原型不得晋升，以及旧 B/S、
PostgreSQL、多用户认证和云部署禁入。

**Input**: 将完整 B/S 幼儿园管理系统重置为本地优先、单教师、多班级的桌面系统；首期交付
一日活动计划、可选 AI、固定 Word 导出和本地/远程加密备份。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 离线完成一日活动计划 (Priority: P1)

教师在没有账号、服务器和网络的电脑上，为任一班级和日期创建、编辑、查找、归档并导出
一日活动计划。应用重启后内容仍然存在，自动保存不会制造大量历史版本。

**Why this priority**: 这是首期产品脱离 Cloud 和 AI 后仍须独立成立的核心价值。

**Independent Test**: 在断网 Windows 电脑首次启动应用，配置幼儿园、学期和两个班级，为
其中一个班级完成教案、重启应用、归档并按固定模板导出，即可独立验收。

**Acceptance Scenarios**:

1. **Given** 应用首次启动且没有数据库，**When** 教师完成最少设置并新建教案，**Then** 应用
   建立本地数据并允许立即编辑，不要求注册、登录或连接服务器。
2. **Given** 教师停止输入约 3 秒，**When** 自动保存完成，**Then** 固定位置显示已保存状态，
   当前正文持久化且不创建历史快照。
3. **Given** 教师显式保存版本，**When** 填写可选版本说明，**Then** 创建可查看、不可变且可
   恢复的历史快照。
4. **Given** 教案已归档，**When** 教师打开它，**Then** 默认只读；恢复归档后才能继续编辑。
5. **Given** 教师选择 Word 导出，**When** 导出完成，**Then** 输出保持固定模板结构和样式，
   原模板不发生改变。
6. **Given** 教师位于某日教案，**When** 直接选择导出当天 Word，**Then** 只导出当前选中日期
   的教案。
7. **Given** 教师选择同一学期内的起止日期，**When** 确认批量导出，**Then** 系统预览将导出
   和跳过的日期，并把已有教案按日期升序合并为一个 Word 文件，每日内容从新页开始。

---

### User Story 2 - 可选使用 AI 与受控 Agent 辅助 (Priority: P2)

教师可以选择配置一个兼容模型，并先使用现有结构化生成能力；随后受控单 Agent 可以通过已
注册 Tool 读取当前上下文、形成草案，并在写入阶段通过精确 Patch 和逐次确认修改正文。任何
模型结果都不能绕过教师控制或 Application Layer。

**Why this priority**: AI 提升编写效率，但不能成为手工主流程或本地数据可用性的前置条件。

**Independent Test**: 使用不访问真实网络的模型替身，分别验证 Slice 2A 的单栏、一键生成、
部分失败、取消、预览拒绝和明确采用；再用 Scripted Provider 验证 Slice 2B 的单 Agent、Context
裁剪、READ/DRAFT 零写入，以及写入阶段的 Patch、确认、stale 拒绝、审计和事务回滚。关闭 AI
后重复手工与导出流程仍成功。

**Acceptance Scenarios**:

1. **Given** 未配置 AI，**When** 教师使用教案模块，**Then** 手工编辑、历史和导出全部可用，
   AI 入口解释其为可选联网功能。
2. **Given** 已配置 AI，**When** 教师发起生成，**Then** 界面保持可操作并显示单一任务状态，
   重复发起被阻止。
3. **Given** 一键生成中部分栏目失败，**When** 任务结束，**Then** 成功预览仍可分别采用，
   失败栏目可单独重试，原正文不被覆盖。
4. **Given** 预览仍有效，**When** 教师明确采用，**Then** 正文更新并自动创建采用前快照。
5. **Given** 教师关闭应用且生成尚未完成，**When** 下次启动，**Then** 不自动恢复该任务，
   已保存正文保持不变。
6. **Given** Slice 2B 已启用，**When** 教师要求 Agent 查看当前教案并提出修改，**Then** 单一
   Runtime 只通过 READ/DRAFT Tool 返回裁剪后的事实和 `PlanPatch`，数据库、版本和正文不变。
7. **Given** Provider 请求未知 Tool、WRITE Tool 或越权字段，**When** Runtime 校验请求，
   **Then** 请求被拒绝且 Provider 不能访问 Repository、Session、文件、凭据或任意代码执行。
8. **Given** Agent 写入阶段已启用且精确 Patch 完整展示，**When** 教师明确确认，**Then** 系统
   在一个短事务中重检 revision/字段摘要，原子创建操作前快照、应用 Patch、更新 revision 并
   记录最小审计。
9. **Given** Patch 被拒绝、修改、过期、重复使用或确认后业务 revision 已变化，**When** Runtime
   尝试写入，**Then** 零写入并要求重新生成和再次确认。
10. **Given** 应用关闭或教师结束 Agent 会话，**When** 下次启动或开始新 turn，**Then** 系统
    不恢复对话、Context、Patch、Confirmation 或长期业务记忆，只从 SQLite 经 READ Tool 重建事实。

### User Story 3 - 备份和恢复本地数据 (Priority: P3)

教师可以把全部本地数据备份到指定文件，并可选配置 WebDAV 或 S3 保存本机加密后的备份。
远程不可用不影响本地保存，恢复始终由教师选择具体版本并明确确认。

**Why this priority**: 单机数据的可恢复性是正式使用的前提，但远程备份不能演变成同步系统。

**Independent Test**: 用包含虚构教案的数据执行本地备份、损坏模拟、恢复前保护性备份、
WebDAV/S3 替身上传失败和跨新安装恢复，即可独立验收。

**Acceptance Scenarios**:

1. **Given** 当天尚未自动备份，**When** 应用首次启动，**Then** 创建轮换本地备份且最多保留
   最近 30 份每日备份。
2. **Given** 教师执行恢复，**When** 选择一个有效备份并确认，**Then** 应用先备份当前数据，
   再恢复所选版本并验证其完整性。
3. **Given** 已配置 WebDAV 或 S3，**When** 上传备份，**Then** 远端只收到本机加密的完整备份
   文件，不收到可直接打开的数据库或明文凭据。
4. **Given** 远程连接失败，**When** 自动或手动备份结束，**Then** 本地数据库继续正常保存，
   界面显示失败原因和重试入口。
5. **Given** 新电脑选择远程备份，**When** 教师没有正确恢复口令，**Then** 应用拒绝解密且不
   提供绕过或万能恢复方式。

---

### User Story 4 - 以现代桌面界面管理多个班级 (Priority: P4)

教师在一个适合长文本工作的现代桌面界面中切换班级、日期和历史记录，并能随时理解保存、
AI 和备份状态。

**Why this priority**: 旧本地 Web 体验已被维护者判定不适合；桌面交互质量是方向重置的关键。

**Independent Test**: 在 Windows 1366x768、125% 和 150% 缩放下，用虚构的两个班级和长篇
教案执行创建、切换、编辑、历史恢复和 AI 预览，检查无关键内容遮挡且无需浏览器。

**Acceptance Scenarios**:

1. **Given** 教师管理多个班级，**When** 切换班级或日期，**Then** 当前上下文始终清晰，未保存
   状态不会静默丢失。
2. **Given** 1366x768 的最低窗口，**When** 编辑长文本，**Then** 核心编辑区域可用，辅助区域
   可以折叠，主要操作无需水平滚动。
3. **Given** 保存、生成或备份正在进行，**When** 状态变化，**Then** 状态在固定位置更新，普通
   成功不弹出阻断式对话框。
4. **Given** 教师选择浅色、深色或跟随系统，**When** 主题立即切换或 Windows 系统主题变化，
   **Then** 全部页面使用一致主题，当前编辑和未保存内容不受影响，选择在重启后保持。
5. **Given** 教师查看一周日期，**When** 浏览日期轨道，**Then** 每个工作日同时显示日期、星期
   和当天集体活动主题，没有主题时显示明确的待填写状态。
6. **Given** 教师位于任意教学周，**When** 选择上一周、下一周或回到本周，**Then** 日期带、
   周次和教案上下文一起更新，当前未保存内容不会静默丢失。

### Edge Cases

- 数据库不存在、为空、损坏、只读或磁盘空间不足时，应用不得伪造保存成功。
- 应用在自动保存、数据库迁移、备份或恢复期间异常退出时，最近一次已确认数据必须可恢复。
- 所选日期不在学期内、不是工作日或超出节假日数据覆盖年份时，只提示，不阻止保存。
- 本地人工标记的上课/不上课状态优先于内置日历，并能撤销回到内置判断。
- AI 超时、返回结构错误、教师切换栏目或正文变化时，不得采用过期预览覆盖正文。
- 忘记远程备份恢复口令时，应用必须明确说明备份无法解密且不泄漏密文细节。
- Windows 凭据项丢失时，本地手工流程仍可使用，并允许教师重新配置外部服务。
- 卸载、升级或安装新版本不得默认删除用户数据库和备份。
- 批量导出范围跨越学期时不得开始生成；范围内没有已有教案时必须禁止导出。
- 批量导出遇到周末、节假日或尚无教案的日期时必须跳过，并在导出前说明日期和原因。
- 批量导出被取消或生成失败时不得留下看似成功但内容不完整的最终 Word 文件。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 系统必须在无账号、无服务器、无网络的条件下完成首期手工教案闭环。
- **FR-002**: 系统必须允许一位教师管理多个班级、学期、班级年龄段和室内/户外区域。
- **FR-003**: 首期不得保存幼儿姓名、照片、观察记录或其他幼儿个人信息。
- **FR-004**: 同一班级和日期必须只有一份当前教案；日期异常只能软提示。
- **FR-005**: 系统必须在停止输入约 3 秒后自动保存，并提供显式保存版本。
- **FR-006**: 自动保存不得创建快照；显式保存版本、AI 采用、历史恢复、归档和恢复归档必须
  按操作语义创建不可变历史快照。
- **FR-007**: 归档教案必须默认只读，恢复归档后才能编辑。
- **FR-008**: 系统必须支持按班级、日期、学期和归档状态查找教案。
- **FR-009**: 系统必须基于固定模板副本导出 Word，保持模板结构和样式且不得修改原模板。
- **FR-010**: AI 必须是可选联网功能；系统只能配置一个当前模型和一组可恢复默认值的提示词。
- **FR-011**: API Key 和远程服务凭据不得进入业务数据库、备份文件或日志。
- **FR-012**: 系统同一时间只能运行一个 AI 生成操作，并必须保持界面响应。
- **FR-013**: AI 结果必须先预览；只有教师明确采用有效预览后才能更新正文和创建快照。
- **FR-014**: 首期 AI 必须支持四栏一键生成、四栏独立生成和一日活动反思；一键生成的部分
  失败不得撤销成功预览或覆盖原正文。
- **FR-015**: 系统关闭后不得自动恢复未完成 AI 任务。
- **FR-016**: 系统必须提供本地备份、每日轮换备份、指定版本恢复和恢复前保护性备份。
- **FR-017**: 系统可以配置 WebDAV 或 S3 作为单向远程备份目标，但不得展示或实现多设备同步。
- **FR-018**: 远程备份必须在本机使用独立恢复口令加密；没有正确口令时必须拒绝恢复。
- **FR-019**: 远程备份失败不得阻断或回滚本地数据库保存。
- **FR-020**: 节假日和调休判断必须支持本地人工覆盖；无可靠数据时显示“待确认”且不阻止保存。
- **FR-021**: 应用必须在最低 1366x768 窗口和 Windows 125%/150% 缩放下保持核心流程可用。
- **FR-022**: 应用升级和卸载不得默认删除业务数据库；Schema 升级前必须自动备份。
- **FR-025**: 首期必须支持浅色、深色和跟随 Windows 系统主题；切换必须即时生效并持久化，
  颜色不得成为状态、错误或选择的唯一表达。
- **FR-026**: 教案日期轨道必须同时显示日期、星期和当天集体活动主题，并允许主题为空时仍
  清楚识别对应教案。
- **FR-027**: 周计划工作台必须提供上一周、下一周和回到本周操作，并同时显示当前教学周次
  与日期范围；切换周次时必须保护当前未保存内容。
- **FR-028**: 01–05 栏目的编辑界面必须按固定 Word 模板的语义字段分格呈现，不得把整个栏目
  降为一个无结构大文本框；教师在界面中看到的字段分组必须能无歧义映射到导出单元格。
- **FR-029**: Word 导出入口必须同时提供直接导出当前选中日期和按自选日期范围批量导出；
  批量范围必须位于同一学期内，除此之外不得人为限制天数。
- **FR-030**: 批量导出前必须显示将导出的教案数量以及被跳过日期的明细和原因；周末、节假日
  与尚无教案的日期必须跳过，范围内没有可导出教案时不得继续。
- **FR-031**: 批量导出必须把已有教案按日期升序合并为一个 Word 文件，每日使用完整模板内容
  并从新的一页开始，不得为每个日期生成独立 Word 文件。
- **FR-032**: 批量导出必须显示进度并允许取消；系统必须先生成临时文件，全部成功后才形成
  最终文件，取消或失败不得留下不完整的最终文件。
- **FR-033**: 系统只能装配一个位于 Application Layer 的 Agent Runtime，同一时刻最多执行
  一个 Agent turn；不得引入隐藏子 Agent、多 Agent 委派或并行 Tool 执行。
- **FR-034**: Provider 对业务能力的全部访问必须经过已注册、类型化且声明 Permission 的 Tool；
  Provider 不得直接访问 Repository、Session、SQLite、文件、凭据、Widget 或任意代码/网络能力。
- **FR-035**: `AgentContext` 必须是按 turn 构建的最小冻结快照，排除秘密、绝对路径、无关业务
  数据和对象引用，并携带相关实体 revision。
- **FR-036**: Slice 2B 只能开放 READ/DRAFT Tool；DRAFT 可以返回规范 `PlanPatch`，但不得打开
  写事务、持久化 Agent preview/对话或改变任何业务状态。
- **FR-037**: Agent 写入必须使用字段级 `PlanPatch` 和教师逐次明确 `Confirmation`；确认必须
  绑定 Patch hash、目标、base revision、会话/turn、有效期和一次性 nonce。
- **FR-038**: WRITE 必须在确认后开启短事务，重新校验 revision、字段摘要和业务不变量，并
  原子完成操作前快照、完整 Patch、revision 更新和最小审计；失败必须全部回滚且不得自动重试。
- **FR-039**: Agent Runtime 必须通过供应商中立的 Provider port 使用当前模型；具体 Provider
  SDK 类型、消息、stream event 和异常不得泄漏到 Application Layer Interface。
- **FR-040**: Agent loop、Provider 和 Tool 必须遵守冻结 DTO 与每线程独立 Session 契约；
  Provider 等待、教师确认和 UI 主线程期间不得保持写事务或跨线程传递 Widget/Session。
- **FR-041**: 首期不得持久化 conversation/thread/message、embedding、向量索引、教师画像、
  自动摘要或 Provider 托管状态作为长期业务记忆；新 turn 必须经 READ Tool 重建权威事实。

### Frozen Future Constraints *(not part of first-release acceptance)*

以下约束冻结后续方向，但不属于本首期 Functional Requirements、任务覆盖率或完成门禁：

- **FC-001（后续分发）**: 首期标准 Windows 安装程序完成后，后续分发必须同时支持 Microsoft
  Store MSIX 与未签名 EXE；未签名 EXE 只能提示更新并打开 HTTPS 下载页，不得静默下载执行
  或规避系统安全提示。
- **FC-002（下一期）**: 紧接首期的下一期必须增加 `.docx` 原始教案导入、AI 拆分/补全、采用
  拆分结果和新增适龄环节；新增失败不得回滚已采用的拆分结果。
- **FC-003（继续延后）**: Level 3 Workflow、多 Agent、跨步骤自治、定时/无人值守 WRITE 和
  长期业务记忆必须经过新的 Design、ADR 与 Issue；首期不得预建调度器或兼容空壳。

### Key Entities *(include if feature involves data)*

- **应用资料**：稳定应用标识、数据 Schema 版本和非敏感用户偏好。
- **幼儿园设置**：幼儿园名称和固定业务时区。
- **班级**：教师在本机管理的班级名称、年龄段及活动区域。
- **学期**：名称、起止日期和当前学期标记，用于日期提示和教学周计算。
- **教案**：班级、日期、当前内容、归档状态和最近保存时间。
- **教案版本**：不可变内容快照、创建原因、可选说明和创建时间。
- **日历覆盖**：某日由教师明确设置的上课/不上课状态，优先于内置日历。
- **AI 非敏感配置**：兼容接口地址、模型名和提示词；秘密凭据位于业务数据之外。
- **AI 预览**：生成栏目、结构化结果、冻结输入摘要、有效性和采用状态。
- **Agent Context**：当前 turn 的最小冻结业务投影、实体 revision 和允许权限；不持久化。
- **PlanPatch/Confirmation**：待审阅字段差异及与其 hash、目标、revision、会话绑定的一次性确认；
  不属于长期业务状态。
- **Agent 写入审计**：只记录 Tool、目标、Patch/确认标识、revision、结果和时间的不可变最小元数据。
- **备份清单**：备份标识、创建时间、Schema 版本、校验信息、目标和加密元数据。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 新用户无需安装服务器或数据库，即可在首次启动流程中完成基础设置并成功创建第一份教案。
- **SC-002**: 在断网条件下，核心手工流程和 Word 导出 100% 可完成。
- **SC-003**: 自动保存状态在停止输入后 5 秒内可见；模拟重启后最后一次成功保存的正文无丢失。
- **SC-004**: 1366x768、125% 和 150% 缩放的 Windows 验收中，全部主要操作可达且无关键控件遮挡。
- **SC-005**: AI 生成失败、取消或预览过期的验收矩阵中，教师原正文 100% 保持不变。
- **SC-006**: 本地备份恢复和远程加密备份恢复均能还原完整虚构数据，错误口令 100% 被拒绝。
- **SC-007**: 远程备份不可用时，连续 100 次本地编辑与保存不因远程故障失败。
- **SC-008**: Word 回归检查确认模板表格、字段位置、字体、字号、段落和换行满足固定模板契约，原模板哈希不变。
- **SC-009**: 浅色和深色主题在最低窗口及 125%/150% 缩放验收中均无不可读文本、丢失焦点
  轮廓或仅靠颜色表达的关键状态，切换主题不丢失编辑内容。
- **SC-010**: 使用包含已有教案、周末、节假日和空缺日期的完整学期样本执行批量导出时，
  导出预览与实际合并日期 100% 一致，输出仅有一个 Word 文件且每日内容均从新页开始。
- **SC-011**: Scripted Provider 验收矩阵中，未知/越权 Tool、未确认/过期/复用/不匹配确认和
  stale Patch 100% 零写入；有效确认只改变展示字段，快照、revision 与最小审计同事务成功。
- **SC-012**: 扫描 SQLite、备份、日志和重启状态时，Agent 对话、Context、ToolResult、Patch、
  Confirmation、embedding 和 Provider 托管 thread 残留均为 0；只允许业务结果和最小写入审计。

## Assumptions

- 首期正式支持 Windows，Linux 仅用于开发，macOS 发布验收延后。
- 一台电脑同一时间只有一位教师使用，不存在共享文件夹并发打开数据库的受支持场景。
- 教师具备可写的 Windows 用户数据目录，并负责保管远程备份恢复口令。
- 中国法定节假日与调休数据随应用版本更新，超出覆盖范围不会联网猜测。
- WebDAV/S3 服务由用户自行提供；应用不承诺第三方服务可用性。
- 旧 `kindergartenManager` 和现有 B/S PostgreSQL 数据均不迁移。
- 移动端、Cloud、多设备同步、多人协作和幼儿个人信息模块不属于首期。
